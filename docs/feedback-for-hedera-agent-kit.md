# Hedera Agent Kit feedback from building this Week 1 demo

1. A first-party `prepare-only` transfer example would help agent builders avoid accidental auto-submit flows.
2. Human-approval examples should show return-bytes or transaction preview objects before signing.
3. Policy hook examples should include max spend, allowlisted recipient, allowed asset, and daily budget controls.
4. HCS audit logging templates for agent decisions would make demos more enterprise-ready.
5. Error messages around missing testnet credentials and account ID format should be copy-paste fixable.

This feedback is ready to adapt into the required public GitHub issue/comment if Drizzy approves entering the bounty.
